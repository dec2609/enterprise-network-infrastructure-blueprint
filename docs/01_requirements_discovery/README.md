# CHAPTER 1: REQUIREMENTS DISCOVERY & MARKET ANALYSIS

## Executive Summary
Chapter 1 establishes the empirical foundation of the project by analyzing real-world recruitment data and industry frameworks. It converts raw market demands into actionable system requirements.

## Document Directory
* [`requirements_discovery.md`](./requirements_discovery.md): Analysis report of explicit keywords and qualitative trends extracted from 157 Vietnamese IT Job Descriptions.
* [`market_requirements_analysis.md`](./market_requirements_analysis.md): Technical translation matrix mapping market demand to specific laboratory design choices.
* [`scope_definition.md`](./scope_definition.md): Formal definition of in-scope capabilities (L2/L3 infrastructure, security boundaries) and out-of-scope boundaries for Version 1.0.
