# RESEARCH & PROVENANCE LAYER (STAGE A -> J)

## Overview
This directory houses the foundational research artifacts, qualitative analysis pipelines, and raw market data that justify the technical scope of the **Enterprise Network Infrastructure Blueprint**.

## Pipeline Structure
* `automation/`: Python notebooks and collection scripts (`collect_jobs.ipynb`, `pdf_extractor.ipynb`, `evidence_pipeline.ipynb`).
* `raw/`: Unprocessed qualitative datasets (`raw_jobs.csv` containing 157 JDs, Cisco CVD text, vendor comparisons).
* `pipeline/`: Sequential qualitative synthesis outputs (Stages B through I: Open Coding, Emergent Themes, Vendor Neutral Requirements, SME Scenarios, and Architecture Mapping).
